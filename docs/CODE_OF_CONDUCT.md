# Code of Conduct

## Our Commitment

The Dart Vader project is committed to providing a welcoming, respectful, and collaborative environment for all contributors.

We believe that a healthy community is built upon mutual respect, constructive discussion, and a shared commitment to improving the project.

All participants are expected to contribute positively to the community regardless of experience level, background, identity, nationality, disability, personal characteristics, or technical expertise.

## Expected Behaviour

Contributors are expected to:

* Be respectful and courteous towards others.
* Engage in constructive and professional discussions.
* Accept feedback gracefully and provide feedback respectfully.
* Focus discussions on the project and its improvement.
* Support new contributors and help them learn.
* Respect differing opinions and approaches.
* Act in good faith when participating in discussions and reviews.
* Follow project policies and maintainer decisions.

## Unacceptable Behaviour

The following behaviours are not acceptable within the Dart Vader community:

* Harassment, intimidation, or personal attacks.
* Discriminatory or hateful language.
* Threatening behaviour.
* Deliberate disruption of project discussions or development.
* Trolling, inflammatory comments, or bad-faith arguments.
* Publishing private information without permission.
* Repeatedly ignoring project policies or maintainer instructions.
* Any conduct that would reasonably be considered inappropriate in a professional software development environment.

## Communication Standards

Disagreements are a normal part of software development. Contributors are encouraged to:

* Critique ideas rather than individuals.
* Explain technical concerns clearly and respectfully.
* Seek understanding before making assumptions.
* Remain professional during discussions, even when disagreements occur.

Project decisions should be based on technical merit, project goals, maintainability, security, and user benefit.

## Reporting Concerns

If you experience or witness behaviour that violates this Code of Conduct, please contact the project maintainers.

Reports should include:

* A description of the incident.
* Relevant screenshots or evidence where available.
* Any contextual information that may assist investigation.

Reports will be reviewed as promptly as possible.

## Enforcement

Project maintainers are responsible for enforcing this Code of Conduct.

Maintainers may take any action deemed necessary to protect the health of the project and its community, including:

* Providing informal guidance.
* Requesting behavioural changes.
* Removing inappropriate content.
* Restricting participation in project discussions.
* Revoking contributor privileges.
* Permanently banning individuals from participating in the project.

Enforcement decisions are made at the discretion of the maintainers.

## Scope

This Code of Conduct applies to all project spaces, including:

* GitHub repositories
* Issues
* Pull Requests
* Discussions
* Project documentation
* Official communication channels relating to the Dart Vader project

## Maintainer Responsibility

Maintainers are expected to:

* Apply this policy fairly and consistently.
* Act professionally and impartially.
* Encourage constructive participation.
* Prioritise the long-term health of the community and project.
